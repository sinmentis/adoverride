Make Azure DevOps easier to read.

Pull requests
- More room for code. Files in a drawer or bottom panel.
- Separate Activity, Description, and Checks tabs.
- Fold commit lists and passed checks.

Work items
- Hide fields, move sections, and widen the reading area.
- Save layouts and undo changes.

Boards
- Wider columns, fewer card fields, and automatic card loading.

Only changes your view. Settings stay local. No ads or analytics.
Free and open source. Works on dev.azure.com and *.visualstudio.com. Some features need English labels.
