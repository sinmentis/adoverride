ADOverride 0.11.23 - release kit

This kit is prepared locally. It has not been submitted to Chrome Web Store or published as a GitHub release.

1. Open PREVIEW.html to inspect the five promotional screenshots.
2. Read chrome-web-store.md for the full store checklist, reviewer instructions, and public developer-address settings. Publisher contact details are account settings, not part of the extension package.
3. Review and commit the pending source, images, and privacy policy. Push to main, wait for CI, and follow publishing.md to publish the approved v0.11.23 tag. No script in this kit publishes anything.
4. Download the resulting adoverride-0.11.23-chrome.zip and SHA256SUMS from GitHub Releases. Use that matching artifact/checksum pair for the store submission. The included ZIP/checksum pair is the locally tested candidate.
5. Open https://chrome.google.com/webstore/devconsole and select the existing item ijeoidnjoamdkpfgbnhfajddhpakobjo. Do not create a new item.
6. Upload only the Chrome extension ZIP in the package section, not a source archive or the outer release-kit ZIP.
7. Paste store/LISTING.txt into the detailed description. Replace the screenshots in the order below. The manifest supplies the title and short description.
8. Review Privacy practices, including transient file paths/reviewed states, saved blocked-author names, and explicit native review-checkbox clicks. Confirm the linked privacy policy is current before submission.
9. Save and submit for review. Choose the dashboard's publication timing yourself. After publication, check the version, screenshots, and public developer details while signed out.
