# ADOverride 0.11.23

Give PR code more room with a searchable file drawer or a bottom navigation panel. The layout stays on while the native PR header, tabs, comments, and actions remain available.

- Choose Drawer or Bottom panel under **PR > Files > Wide Files layout > File navigation**.
- Pin the drawer beside the code, or minimize the bottom panel to reclaim height.
- Search file paths and filter to unreviewed files. Selecting a file never marks it reviewed automatically.
- Keep the native tree when folders are collapsed, the inventory is incomplete, or controls are not recognized.
- Resize the actual code editor when the layout changes. Azure DevOps' editor needs a resize notification, not just a wider outer container.

No new permissions or separate file-inventory requests. Existing Board and Ticket settings are preserved.
